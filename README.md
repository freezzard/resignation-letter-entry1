Entry for the make.fun bounty **The Funniest One-Line Resignation Letter**. `main.ts` assembles one original one-line resignation letter, checks it against the competition gate (1–140 characters, one line, not only white space) plus a few craft rules of its own, and writes it to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The letter (106 characters): a cron job resigns after 400,000 runs since March, because its whole performance review is a single log line nobody has ever read.

## Run it

```sh
node main.ts
```
